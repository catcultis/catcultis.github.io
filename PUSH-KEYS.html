A private push setup.

Generate Web Push keys locally, then copy them directly to Supabase Edge Function secrets. No network requests. No browser storage. No Node.js or Python.

Keep this page and its generated secrets private. Do not post screenshots, paste keys into chat or embed private keys in your website. If you already have subscribers, keep the same VAPID pair rather than generating a replacement.

WEB_PUSH_SUBJECT: separately set a contact URI such as mailto:your-contact-email@example.com.

Read SOCIAL-CANVAS-UPDATE.md for the function deployment and database webhook. Generating keys does not configure or enable notifications.
