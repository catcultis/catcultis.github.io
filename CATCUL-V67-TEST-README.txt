CATCUL v67 — TEST WEBSITE PACKAGE

This is a test build, not the completed update. It was not published by the assistant. Back up your current site first; unzip at your existing website root, replacing matching files while keeping your other assets and user files. This build uses your existing live Supabase project even from a preview/staging URL: test actions create or change real data. Use a dedicated test group and non-sensitive test content. No SQL needs to be rerun for the games included here.

LOOK: brighter chat headers, colorful room and game menus, refreshed game surfaces, and polished cards and controls in light and dark modes. Custom wallpapers remain unchanged. Check desktop, phone, dark mode and your custom wallpapers.

GUIDE: Open Catcul Guide from the landing page, Help Centre or the workspace menu. It includes searchable help for chats, games, calls, room cats, privacy and troubleshooting, and works as a static page. Its source can be updated when future versions are built.

GAMES TO TRY: Most Likely To, Imposter Cat, Two Truths and a Lie, and Word Chain, in a signed-in group chat's menu. Word Chain checks letter format and repeats, not dictionary validity. Browser tests used mocked servers, and some database tests used rolled-back transactions; real concurrent people and devices have not been proven. Word Bomb, Mafia and Drawing Telephone are NOT included or enabled yet. Word Bomb has additional local PostgreSQL role, concurrency and two-automated-browser fixture tests, but its live backend is not deployed. Mafia has an unfinished server and UI draft with isolated fixture and automated browser tests; it is not enabled or included.

GROUP CHAT CAT: Open a signed-in group chat > chat menu > Group corner. The shared room cat levels up from eligible saved messages and completed multiplayer typing races; deleted messages no longer count. Posting members can select unlocked outfits. Wave and spin unlock at higher levels and are transient realtime effects for connected viewers, not persistent tricks. This test build improves outfit refresh handling, touch targets and dark-mode readability. The existing backend is live; no new migration is required. Mock browser tests passed; real users and devices remain untested. Cat notes and other richer features are not finished.

3D CULJI ADMIN: Admin > Culji > 3D mesh studio > Open 3D mesh editor. Select Pull or Push and choose a part and tap it, or use Brush selected part center; Rotate lets you drag. Undo, reset, brush size and strength are available. This actually moves vertices of the 3D Culji's head, torso, outer ears and shoe uppers. It does NOT edit all body parts, hair, facial features, clothing details or shoe soles, and those separate pieces do not automatically follow your edits. Left/right are from the front view. It is a LOCAL DRAFT ONLY: it does not change the site-wide model, other people’s Culjis or published artwork. Tab storage may preserve a draft during tab navigation; download a JSON copy before closing, and use Open mesh draft to restore it. No untrusted draft is automatically published. WebGL required; physical-device support is not verified. The separate Publish starting look button still changes only the existing homepage starting appearance, not your mesh draft.

GUEST VOICE: NOT included or enabled. Restricted-host voice for admin and @nety is still under development; it needs the issuer, safe cleanup and expiry worker, real-device and race tests before activation.

PHOTO/VIDEO: Photo compression is in progress and may reduce visual quality; actual resolution depends on source and device. Video compression and aggregate storage-budget enforcement are not yet implemented. Supabase limits remain.

Service worker cache was updated. If you see old pages, close and reopen the site after your host has deployed the new files.
