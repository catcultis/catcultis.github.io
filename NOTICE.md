This folder includes Jeeliz FaceFilter and the Butterfly, Tiger, Cloud and Fireworks demonstration code and assets from https://github.com/jeeliz/jeelizFaceFilter, commit `6f2695120b992511fd6cb1fd80c600bb957cd08c`. Jeeliz identifies the included demos and library as Apache License 2.0; the complete license is in `LICENSE`.

The demo `main.js` files were modified to integrate startup, error handling and photo capture with Catcul; the tiger demo's initial particle scale was adjusted. Their original demo pages were replaced with Catcul integration pages. `bridge.js` is Catcul integration code.
